# Distance law

`hicstuff.distance_law` computes the distance law from a pairs file
(`get_distance_law`), reads and writes its tables (`import_distance_law`,
`export_distance_law`), normalises and averages the curves
(`normalize_distance_law`, `average_distance_law`) and plots them with their
slope (`plot_ps_slope`). See [The distance law](../guides/distance-law.md).

::: hicstuff.distance_law
